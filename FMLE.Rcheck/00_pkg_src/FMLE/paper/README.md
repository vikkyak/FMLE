# Paper materials

This directory contains manuscript-specific figure scripts, dataset preparation code,
and benchmark workflows used for the FMLE paper.

These files are intentionally kept separate from the package-facing API.
They are not required to install or use the `FMLE` package.

## Layout

- `analysis/`: figure and validation scripts used in the manuscript.
- `scripts/`: dataset-specific preparation and benchmark scripts.

## Reproducibility

The package itself is designed for installation and end-to-end method use.
The code in this folder is for paper reproduction and large-scale benchmark workflows.
